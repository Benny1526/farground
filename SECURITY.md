# Security policy

## Supported versions
Security fixes go into the latest Farground release, for each Minecraft version it supports.
Please update to the latest release before reporting.

## Reporting a problem
Please **don't** open a public issue for a security problem, for example a way for a player on a
server to make it crash, delete files, or run code.

Report it privately instead: on the repository's **Security** tab, choose
[**Report a vulnerability**](https://github.com/Benny1526/farground/security/advisories/new).
Include the Farground and Minecraft versions, the loader, and the steps to reproduce it.

You'll get an answer as soon as possible. Once a fix is released, the report can be made public,
with credit to you if you like.
